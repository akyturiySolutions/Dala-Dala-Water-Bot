Dala Dala Full System (Bot + Firebase + Dashboard)

SETUP:

1. Install dependencies:
npm install express axios body-parser dotenv firebase-admin

2. Add your Firebase serviceAccountKey.json in root

3. Create .env file:
WHATSAPP_TOKEN=your_token
PHONE_NUMBER_ID=your_phone_id

4. Run:
node app.js

5. Open dashboard:
Open dashboard.html in browser OR host online
